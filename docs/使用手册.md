## 1. 开始使用

### 登录

打开管理员提供的地址，使用邮箱与密码登录。首次部署的默认账号为：

```
admin@kbpro.local / admin12345
```

> 登录后请立刻到「个人中心 → 安全」修改密码。

### 注册

若实例开启了注册（默认开启，可在「系统管理 → 实例设置」关闭），点击登录页的「注册」标签，
填写昵称、邮箱与至少 8 位密码即可。注册后系统会自动为你创建一个**个人知识库**。

### 认识界面

```
┌────────────┬──────────────────────────────────────────────────┐
│ 知识库切换 │  面包屑                                搜索 ⌘K   │
│ 新建按钮   ├──────────────────────────────────────────────────┤
│            │                                                  │
│ 导航菜单   │                  当前页面内容                     │
│            │                                                  │
│ 用户信息   │                                                  │
└────────────┴──────────────────────────────────────────────────┘
```

- **左上角知识库切换器**：在「个人知识库」与「团队知识库」之间切换。两者数据完全隔离。
- **新建按钮**：快速新建笔记 / 文件夹 / 上传文件 / 新建知识库。
- **顶部搜索框**（或 `Ctrl/⌘ + K`）：打开命令面板，可直接跳转功能或检索全库。
- **左下角**：进入个人中心。

### 个人知识库 vs 团队知识库

| | 个人知识库 | 团队知识库 |
|---|---|---|
| 可见范围 | 仅自己（可单独共享某份文件） | 团队成员按角色授权 |
| 典型用途 | 我的资料、读书笔记、灵感 | 部门文档、项目资料、企业问答 |

一个账号可以拥有多个个人知识库，也可以加入多个团队。

## 2. 文件库

### 上传文件

三种方式任选：

1. **拖拽**：直接把文件拖到窗口任意位置，会出现全屏提示区，松手即上传到当前知识库（若左侧选中了某个文件夹，则上传到该文件夹）。
2. **按钮**：点击右上角「上传」按钮，或按 `U` 键。
3. **新建菜单**：左下角「新建」→「上传文件」。

支持格式：PDF、Word（doc/docx）、Excel（xls/xlsx）、PPT（ppt/pptx）、Markdown、TXT、CSV、JSON、
HTML、XML、各类代码文件，以及图片、音视频、压缩包。

上传后右下角出现**进度面板**，逐个文件显示上传百分比、大小与结果：

- 上传完成 → 显示「解析中」
- 解析完成 → 提示「《文件名》解析完成，已可检索与问答」
- 解析失败 → 显示失败原因，并提供「重试」按钮
- 扫描件（无文本层）→ 标注「无文本」，并提示需要 OCR

> 同名文件会自动重命名为 `文件 (2).md`，不会覆盖已有文件。

### 浏览与筛选

- **列表视图 / 网格视图**：右上角切换。网格视图对图片文件显示缩略图。
- **排序**：最近更新 / 创建时间 / 名称 / 大小 / 查看次数，再次点击同一项可切换升降序。
- **筛选**：全部 / 仅收藏 / 仅置顶 / 仅加密。
- **搜索框**：在文件库内按名称与内容搜索。

### 单个文件操作

悬停文件行，点击右侧 `⋮`（或右键）打开菜单：

| 操作 | 说明 |
|---|---|
| 打开预览 | 打开详情抽屉（见下） |
| 下载原文件 | 下载原始文件 |
| 收藏 / 置顶 | 置顶文件始终排在列表顶部 |
| 重命名 | 保留扩展名 |
| 移动到… | 选择目标文件夹 |
| 编辑标签 | 标签参与全局检索与知识归类 |
| 设为私密 / 改为继承权限 | 私密文件仅创建者与显式授权者可见 |
| AI 智能解析 | 打开抽屉的 AI 面板 |
| 重新解析并索引 | 解析失败或文档更新后手动重跑 |
| 共享与权限 | 打开共享面板 |
| 导出为 Markdown / HTML | 导出已解析的文本内容 |
| 删除 | 移入回收站（可撤销） |

### 批量操作

勾选文件左侧的复选框（或点击「全选」），底部出现批量操作条：

**置顶 · 收藏 · 加标签 · 移动 · 重建索引 · 导出 · 删除**

按 `Ctrl/⌘ + 点击` 可跨行多选。

### 在线预览

点击文件打开详情抽屉，包含 5 个标签页：

| 标签页 | 内容 |
|---|---|
| **内容** | PDF 内嵌阅读器；Word/Excel/PPT 渲染为结构化 HTML（保留标题、加粗、表格、图片）；Markdown 渲染排版；纯文本与代码等宽显示；图片/音视频直接播放 |
| **AI 智能解析** | 一键生成内容摘要、结构化大纲、关键词与术语 |
| **相关知识** | 基于内容向量的语义关联文档，点击可跳转 |
| **评论** | 团队成员留言讨论 |
| **共享与权限** | 设置访问级别、共享给指定用户、生成分享链接 |

抽屉底部：下载、导出、收藏、置顶、**就此文档提问**（跳到问答页并限定在该文档范围内）。

## 3. 笔记中心

### 新建与编辑

- 点击左上「新建笔记」，或按 `N`，或在命令面板中执行「新建笔记」。
- 标题直接在上方输入框编辑。
- 正文为所见即所得编辑器，光标处直接输入即可。
- 首次登录会自动创建一篇《欢迎使用 KBPRO 知识库》作为上手示例。

### 工具栏

| 按钮 | 说明 | 快捷键 |
|---|---|---|
| **B** / *I* / U / S | 加粗 / 斜体 / 下划线 / 删除线 | `Ctrl+B` / `Ctrl+I` / `Ctrl+U` |
| H1 / H2 / 正文 | 标题级别 | – |
| 列表 | 无序 / 有序列表 | – |
| 引用 | 引用块 | – |
| 代码块 | 插入代码块 | – |
| 表格 | 插入 3×3 表格 | – |
| 图片 | 上传并插入图片（≤ 8 MB） | – |
| 链接 | 插入链接 | `Ctrl+K` |
| 分割线 | 水平分割线 | – |
| 标签 | 编辑笔记标签 | – |
| 清除格式 | 去除选中文本样式 | – |

> 从网页或 Word 粘贴内容时会自动净化，仅保留安全的排版标签。

### 自动保存

编辑后 **0.9 秒**自动保存，右上角状态点实时反馈：

- 🟡 **编辑中…** —— 有未保存的修改
- 🟢 **已保存 · 14:32** —— 已落库
- 🔴 **保存失败：…** —— 出现错误

也可随时按 `Ctrl/⌘ + S` 手动保存并**立即生成一个版本**。

### 历史版本

点击右上角「版本」按钮打开侧栏：

- 系统在内容变化且（距上次版本 > 40 秒，或改动超过 400 字）时自动留存快照
- 每个笔记保留最近 **30 个**版本
- 点击任意版本可预览完整内容
- 点击「恢复」会**先把当前内容存为新版本**，再切换到所选版本——不会丢内容

### 侧栏信息

「详情」标签页可设置笔记表情图标、编辑标签、查看字数与阅读时长、移动到文件夹、导出 Markdown。

### 笔记列表

- 搜索框按标题与正文搜索
- 排序：最近更新 / 创建时间 / 标题 / 字数
- 筛选：全部 / 仅收藏 / 仅置顶
- 右键笔记可快速重命名、收藏、置顶、删除

## 4. 分类文件夹

独立的目录管理控制台，与文件库左侧的目录树功能互补（此处功能更完整）。

### 目录树

- 点击文件夹前的三角形展开 / 收起（带动画）
- 每个节点显示文件数量
- 点击 `⋮` 或右键：新建子文件夹 / 重命名 / 移动到… / 更改图标 / 删除

### 拖拽整理

直接把一个文件夹拖到另一个文件夹上即可移动，拖到「未分类（根目录）」则移回顶层。

> 系统禁止把父文件夹移动到自己的子目录中，会给出明确提示。

### 删除文件夹

删除时会要求你明确选择处理方式：

- **保留内容，移动到根目录**（推荐）—— 文件夹消失，里面的文件与笔记回到顶层
- **连同内容一起移入回收站** —— 文件和笔记一并进入回收站，可恢复

### 批量整理

勾选多个文件夹后可批量移动；「未分类」节点可一次性把散落内容归类到指定目录。

## 5. 全局检索

按 `Ctrl/⌘ + K` 打开命令面板，输入关键词后回车，或在左侧导航点击「全局检索」。

### 检索框

输入即搜（约 260ms 防抖），回车立即检索并把查询写入地址栏（可分享/收藏该链接）。

支持四种检索模式：

| 模式 | 适用场景 |
|---|---|
| **智能混合**（默认） | BM25 关键词 + 向量召回 + RRF 融合，综合效果最好 |
| **关键词** | 明确知道原文用词，追求精确匹配 |
| **语义向量** | 按语义相近程度召回 |
| **模糊匹配** | 关键词都没命中时的子串兜底 |

### 筛选条件

- **类型**：全部 / 文档 / 笔记
- **知识库范围**：当前知识库 / 全部知识库
- **标签**：多选，来自当前知识库的标签体系
- **仅收藏**
- **文件夹**

### 结果解读

每条结果包含：

- 文件图标（按类型着色）或笔记表情
- 标题（命中关键词高亮）
- **命中片段**（关键词以黄色标记，附带上下文）
- 页脚：类型、所在文件夹、标签、更新时间、相关性分数

点击结果直接打开：文档 → 文件库详情抽屉；笔记 → 笔记编辑器。

结果项右侧 `⋮` 菜单：在新标签打开 / 复制链接 / 打开所在文件夹 / 收藏。

### 快捷筛选

- **最近 7 天更新的文档**
- **我收藏的**
- **全部标签**

### 检索技巧

- 中文检索按**二元组**索引，短词（2–4 字）效果最好
- 用文档中实际出现的词，比用近义词命中率更高（除非已接入大模型 embedding）
- 结果太少时：去掉标签过滤 → 切换到「模糊匹配」→ 扩大到「全部知识库」

## 6. 智能问答（RAG）

这是 KBPRO 的核心能力：**基于你自己的文档回答问题，并给出可追溯的引用来源。**

### 提问

1. 点击左侧「智能问答」（或按 `Ctrl/⌘+K` 搜索「向知识库提问」）
2. 在底部输入框输入问题，回车发送（`Shift+Enter` 换行）
3. 回答会**流式逐字出现**，随时可点「停止生成」

### 理解回答

每条回答下方是**引用来源卡片**：

- 序号角标（与正文中的 `[1]` `[2]` 角标对应）
- 来源文档名称、页码、章节
- 命中的原文片段
- 相关性分数

点击引用卡片可直接跳到该文档；点击正文中的角标会高亮对应卡片。

### 提问范围

输入框上方的范围标签可切换：

- **当前知识库**
- **全部知识库**（跨个人 + 团队）
- **限定文件…** —— 选择若干份文档，只在这些文档中检索（适合「对比这几份合同」这类问题）

从文件详情抽屉点「就此文档提问」，会自动限定到该文档。

### 会话管理

- 左侧是历史会话列表，置顶的排在前面
- 右键 / `⋮` 可重命名、置顶、删除
- 每条回答支持 👍 / 👎 反馈与一键复制

### 关于回答质量

页面顶部会显示当前使用的 AI 引擎：

- **内置本地引擎** —— 回答由原文句子**抽取并组织**而成，完全忠于原文但不会改写成更流畅的表述。
  此时会显示一条提示，引导你配置大模型。
- **已接入大模型** —— 回答为生成式，会综合多份文档、润色表达，同时仍标注引用来源。

无论哪种模式，系统都要求**只依据检索到的文档片段作答**，片段不足时会明确说明而不是编造。

## 7. 团队协作

### 创建团队

「团队协作」→「创建团队」，填写名称与描述。系统会自动创建一个同名的**团队知识库**。

### 邀请成员

1. 进入团队 → 成员标签页 → 「邀请成员」
2. 输入对方邮箱（输入时会实时联想已注册用户）
3. 选择角色 → 发送

> 对方必须**已经注册 KBPRO 账号**，否则会提示先让对方注册。

### 角色与权限

| 角色 | 查看 | 评论 | 编辑 | 成员管理 | 知识库管理 |
|---|:--:|:--:|:--:|:--:|:--:|
| **所有者** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **管理员** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **编辑者** | ✅ | ✅ | ✅ | – | – |
| **评论者** | ✅ | ✅ | – | – | – |
| **只读** | ✅ | – | – | – | – |

所有者额外拥有转让所有权的能力（当前版本未开放在线转让）。

### 共享知识库内容

在文件/笔记详情抽屉的「共享与权限」标签页：

- **访问级别**：设为私密（仅自己与授权者）或继承知识库权限
- **共享给指定用户**：输入邮箱 → 选择权限（只读 / 可评论 / 可编辑 / 可管理）
- **生成分享链接**：生成一个 7 天有效的链接，**对方无需登录即可查看**，复制后发给外部人员

### 协作动态

团队页面的「协作动态」表格实时展示：谁、在什么时间、对哪个对象做了什么操作。
完整审计记录见「系统管理 → 审计日志」。

### 协同编辑

多人同时打开同一篇笔记时：

- 顶部会显示「N 人正在查看」
- 保存过的改动会实时通知其他人
- 若你正在编辑而他人保存了，系统不会强行覆盖你的输入

> 注意：协同采用「编辑锁 + 广播 + 后写覆盖」策略，**不是** OT/CRDT 实时协同。
> 强烈建议同一时间只由一人主笔同一段落。

## 8. 回收站

删除的文件与笔记都会先进入回收站，可随时恢复。

- 顶部标签页切换「文档 / 笔记」
- 表格显示：名称、原位置、大小/字数、时间
- 行操作：**恢复** / **彻底删除**（不可恢复，会二次确认）
- 批量：全选 → 批量恢复 / 批量彻底删除

> 回收站中的文件仍占用存储空间。确认不再需要时请彻底删除。

## 9. 个人中心

### 资料

- 点击大头像上传头像（建议 ≤ 200 KB）
- 编辑昵称、职位、个人简介

### 安全

- **修改密码**：原密码 + 新密码（≥ 8 位，需两次一致），带强度提示
- **当前会话**：登录状态、浏览器信息
- **退出登录**
- **数据安全说明**：了解口令哈希、文件加密、审计日志等机制

### AI 引擎

配置知识库使用的大模型：

| 提供商 | 说明 |
|---|---|
| **自动** | 有 API Key 用 OpenAI 兼容，否则尝试 Ollama，都不可用则用内置引擎 |
| **Ollama** | 本地大模型，数据不出内网。需先 `ollama serve` 并 `ollama pull <模型>` |
| **OpenAI 兼容** | 任意 OpenAI 协议接口（DeepSeek / 通义 / Kimi / vLLM / one-api）。填 Base URL + API Key + 模型名 |
| **内置本地引擎** | 离线抽取式摘要与问答，无需任何配置 |

- 保存后点击「测试连接」验证
- 已保存的 API Key 显示为「已保存密钥」，可点「清除密钥」
- **重建全文索引**：文档解析失败或内容异常时使用
- **重建向量索引**：接入 embedding 模型后，用真实语义向量替换本地哈希向量，可显著提升语义召回

### 存储

- 查看已用空间与配额（未设置配额时显示「不限额」）
- 按文件类型统计占用与占比
- 回收站占用（含前往回收站的快捷入口）
- **导出全部数据**：把当前知识库打包为 ZIP（含 Markdown 文本、原始文件与结构化清单）

## 10. 系统管理

仅管理员可见。

### 概览

用户数、知识库数、文件数、笔记数、知识块数、数据库体积、运行时长、内存占用、Node 版本与平台。

### 备份与恢复

| 类型 | 内容 | 典型用途 |
|---|---|---|
| **全量备份** | 数据库 + 全部文件 | 灾难恢复。耗时较长，建议低峰期执行 |
| **仅元数据** | 数据库（不含文件） | 快速日常快照 |
| **指定知识库** | 单个知识库的元数据与文件 | 交付、迁移到其它实例 |

- 可勾选**加密备份**并设置口令（≥ 6 位），生成 `.kbpro` 包，**仅凭口令即可恢复**
- 备份列表支持下载、恢复、删除
- 恢复全量备份需要**重启服务进程**；恢复流程会先自动生成一份安全快照
- 恢复「指定知识库」类型的备份会**导入为一个新知识库**，不会覆盖现有数据

### 审计日志

记录所有关键操作：登录、登出、上传、下载、检索、共享、备份、AI 调用等。

- 按操作类型、关键词、知识库筛选
- 显示操作时间、操作人、动作、对象与详情
- 支持清理搜索类日志（`search*`）以控制日志体积

### 实例设置

- **单文件上传上限**（MB）
- **是否开放注册**
- **会话有效期**（天）
- **RAG 检索片段数**、**分块大小**、**分块重叠**（修改分块参数后需重建索引才会生效）
- **AI 全局默认**：提供商、Base URL、对话模型、嵌入模型、Ollama 地址、温度、最大 token、全局 API Key

> 会话有效期与上传上限对**新的请求**生效；AI 与分块参数需要后续操作（或重建索引）才会应用。
> 保存设置不会重启服务。

## 12. 常见问题

**Q：上传后一直显示「解析中」？**
大文件（上百页 PDF、大表格）解析需要时间。可查看右下角进度面板，或到文件详情抽屉点「重新解析并索引」。
若长时间无进展，检查服务端日志。

**Q：PDF 打开了但搜不到里面的内容？**
该 PDF 可能是**扫描件**（图片而非文本）。KBPRO 不做 OCR，文件会标注「无文本」。
解决方式：用 OCR 工具处理后重新上传。

**Q：中文 PDF 提取出来是乱码？**
该 PDF 使用了自定义编码的子集字体且未内嵌 `/ToUnicode` 表。这是已知限制，
可尝试用其它工具另存为标准 PDF 后重新上传。

**Q：问答回答说「知识库中暂无相关依据」？**
可能原因：① 相关文档未上传；② 文档还在解析中；③ 提问用词与文档差异较大；
④ 当前所在知识库不对。建议换用文档中出现过的关键词，或切换到「全部知识库」范围。

**Q：回答看起来像是原文摘抄？**
说明当前使用的是**内置本地引擎**。到「个人中心 → AI 引擎」接入大模型即可获得生成式回答。

**Q：团队知识库里的文件我看不到？**
该文件可能被设为**私密**（`acl_level = private`），仅创建者与显式授权者可见。
请联系文件创建者共享给你。

**Q：忘记密码怎么办？**
当前版本没有邮件找回流程。请联系管理员在服务端重置，或由管理员直接修改数据库中的口令哈希。

**Q：能否把数据迁移到另一台服务器？**
可以。在「系统管理 → 备份」中创建**全量备份**（建议加密），把生成的备份包复制到新服务器，
在新实例上通过「恢复」功能导入，然后重启服务。

**Q：多人同时编辑同一篇笔记会冲突吗？**
会有覆盖风险。系统提供编辑锁提示与实时活动通知，但不做字符级合并。
建议同一时间由一人主笔。

**Q：如何提升检索准确率？**
① 给文档打上标签；② 文件名起得具体；③ 提问使用文档中实际出现的术语；
④ 在「个人中心 → AI 引擎」配置嵌入模型后重建向量索引。
